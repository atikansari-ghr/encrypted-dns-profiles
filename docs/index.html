Encrypted DNS Profiles

Installable configuration profiles that switch your iPhone, iPad, Mac, or Android device to an encrypted DNS resolver — no app, no VPN, no account. Ad and tracker blocking happens at the DNS level, before a single request reaches your browser: fewer ads, fewer tracking pixels, and fewer of the pop-ups and redirects that ride in on ad networks. Several of the profiles below go further and block known malware and phishing domains outright, so a poisoned link or a fake login page never gets the chance to load. Setting this up for a child's device? The family-filtering profiles add adult-content blocking and enforced safe search on top — still one profile, still nothing extra to install. Not sure where to start? AdGuard's ad-blocking and family-protection profiles cover the most ground; the comparison table below shows exactly what every profile blocks.

What this does

A DNS profile changes which server your device asks to translate domain names (like example.com) into addresses. Installing one of the profiles below tells your device to send those lookups, encrypted, to a resolver that also filters out ad and tracking domains before they ever load.

This is not a VPN.
  • Your traffic still goes directly to the sites you visit — only the DNS lookup is redirected and encrypted. There is no separate app, no server relaying your browsing, and nothing to sign in to.
  • Once installed, the profile applies system-wide: every app on the device uses the new resolver, not just your browser.
  • It works the same way on every network — Wi-Fi or cellular data (4G/5G) — with nothing extra to set up per network. Your DNS queries resolve through the encrypted resolver either way.

Choose a profile

Each card links to two versions of the same profile: DoH (DNS-over-HTTPS, recommended, works everywhere including iOS/iPadOS/macOS) and DoT (DNS-over-TLS, needed for Android's built-in Private DNS setting). You can install more than one profile — only one is active at a time, and you choose which under Settings.

Install on iPhone or iPad

  1. On your device, tap the Install (DoH) button on the profile card above. (DoT also works on iOS if you prefer it; DoH is recommended because it runs on port 443 alongside ordinary HTTPS traffic, whereas DoT's port 853 is trivially blocked by some networks.)
  2. Safari will open Settings and show Profile Downloaded. Tap it.
  3. Tap Install in the top-right corner, enter your device passcode if asked, then tap Install again on the two confirmation screens.
You will see a red "Not Signed" warning — this is expected.

These profiles are not cryptographically signed by a paid Apple developer certificate, so iOS marks them "Not Signed" in red. This does not mean the profile is unsafe or broken; it means Apple cannot vouch for who published it. You can always inspect exactly what a profile changes (only DNS settings) before installing by tapping "More Details" on the install screen.

You can install more than one profile; iOS keeps them all and lets you pick which one is active under Settings → General → VPN & Device Management.

Install on Android

Android does not use .mobileconfig files. Instead, enter the DoT hostname from the profile card above into Android's built-in Private DNS setting (requires Android 9 or later, and only the DoT hostname — not DoH — works here).

Stock Android

  1. Open Settings → Network & internet → Private DNS.
  2. Choose Private DNS provider hostname.
  3. Paste in the hostname you copied from the profile card (use the Copy button next to it).
  4. Tap Save.

Samsung (One UI)

  1. Open Settings → Connections → More connection settings → Private DNS.
  2. Choose Private DNS provider hostname.
  3. Paste in the hostname and tap Save.

Install on macOS

  1. Click the Install (DoH) button on the profile card above; the file downloads to your Mac.
  2. Open System Settings → General → Device Management.
  3. Select the downloaded profile and click Install, entering your Mac password if asked.

The same "Not Signed" warning described in the iPhone section applies here too, and for the same reason.

Check it is working

  1. Visit dnsleaktest.com and tap Standard test. Confirm the result reports the resolver you just installed, not your ISP's default. You can also use 1.1.1.1/help (Cloudflare) or the test page listed on your provider's homepage above.
  2. For a profile above that blocks ads, visit adblock-tester.com and confirm it reports ads and trackers as blocked. Skip this for the two Cloudflare profiles — they filter malware only, not ads.
  3. If nothing changed, re-check Settings → General → VPN & Device Management (iOS/macOS) or Private DNS (Android) to confirm the profile is installed and active, not just downloaded.
dnsleaktest.com and adblock-tester.com are independent third-party sites

They are not part of this project and not operated by any of the DNS providers listed above. Visiting them sends a request from your device directly to that site to run the check — nothing about the result is sent to or seen by this project. Their own privacy practices are their own; this project does not vouch for them beyond linking to well-known, commonly recommended tools.

Compare resolver speed

Every profile above is encrypted; how fast each one answers depends on your own location and network, not on anything this project controls. Rather than publish a fixed number that would be wrong for most visitors, this runs a real, timed DNS query to each provider directly from your browser.

This is the one thing on this page that runs automatically-on-click network requests to eight third parties.

Nothing is sent to this project. Each request goes straight from your browser to that provider's own resolver, the same way your device would if you installed its profile. A provider blocked or filtered on your network (this happens — some networks block certain DNS providers outright) will show as unreachable rather than a time.

FAQ

Is this a VPN?
No. Only DNS lookups are sent to the new resolver, encrypted. Your actual web traffic still goes directly to each site, exactly as before.
Does it cost anything?
No. Every profile here uses a resolver's free public tier. No account or subscription is required for any of them.
Does it slow down browsing?
DNS lookups are cached by your device and usually happen well before a page loads, so any difference is generally imperceptible. Encrypted DNS can occasionally add a small amount of latency to the first lookup of a new domain compared to plain, unencrypted DNS.
How do I remove a profile?
iOS/macOS: Settings → General → VPN & Device Management (or System Settings → General → Device Management on Mac), select the profile, then Remove. Android: open Private DNS and switch it back to Automatic or Off.
What happens on a network that blocks DNS-over-HTTPS?
Some corporate, school, or hotel networks block encrypted DNS to keep their own filtering in place. If DoH stops working, try the DoT version of the same profile; if both are blocked, the device typically falls back to the network's own DNS, or you can temporarily remove the profile.
Does a VPN interfere with the DNS profile?
Yes. Most VPN apps take over DNS resolution while connected, which suppresses the encrypted DNS profile regardless of which one is active. This is expected — a VPN and a DNS profile both want to control DNS, and the VPN wins. Disconnect the VPN to use the profile, or check whether your VPN provider offers equivalent DNS filtering.
Safari shows raw XML instead of offering to install the profile. What do I do?
Use Safari's Share sheet to save the file (Share → Save to Files), then open it from the Files app to continue the install.
